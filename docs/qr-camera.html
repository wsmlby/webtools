    How to scan

    Use HTTPS and a browser with camera access, such as Safari on iPhone or Chrome on Android. The rear camera is preferred. Keep the code inside the frame, with good lighting. Scanning stops after a result; press Scan again to read another code.

    Only HTTP and HTTPS web addresses become clickable links. Check the address before opening it; links never open automatically.

    For a saved image or a difficult code, try the OpenCV WeChat QRCode Reader.
